# 第二张场诊断图的归因与自动可视化复核

日期：2026-11-22。对象是处理清单 `data/processed/libero_v2` 的 episode 6000，第二个夹爪命令区间 CLOSE `[36,85]`，49 个动作、50 个观测、2.45 s。原图为 `data/experiments/field_visualization_20261122/command_span.png`。本轮实际命令、源码和产物哈希见[机读记录](field_visualization_2026-11-22.json)；原始输出保存在 `data/experiments/field_repair_20261122/`。

## 可确认的原因

这个命令区间不是一个已经验收的动力系统片段。示教到区间末端的距离从 100.885 mm 增到 118.760 mm，然后才接近目标；按存储的平滑速度统计，50 个采样中有 17 个径向外移样本。当前场满足 `(p-g)·f(p)<0`，离散反馈限制也保证欧氏目标距离下降。

若名义轨迹从相同初始位置开始，它到最终目标的距离不能超过初始半径 `r0`。由三角不等式，每个源时刻的位置误差至少为 `max(0, ||p_demo(t)-g||-r0)`；50 个时刻合成的 RMS 下界为 **10.713 mm**，高于现有 **10 mm** 验收门槛。由此可确定：在相同目标、初态和当前欧氏下降约束下，这整个区间无法通过门槛，不能只靠增加优化次数解决。

同时，原拟合的三个重启都到达 300 次上限，并非已证收敛的最优解；姿态使用固定末端目标反馈，其 RMS 为 5.101°，也略超 5° 门槛。示教有限差分最高速度约 0.253 m/s，低于本次 0.3 m/s 限速；拟合场自身仍会触发离散下降限制。不能把全部误差归为示教超过限速，也不能据此宣称原 SEDS 算法不能学习该任务。

## 实际对照

所有位置 RMS 都按源时间对齐。局部统计每个片段从该段真实初态重新积分，公共边界只计一次。连续统计从 `[36,85]` 的初态积分一遍，按源分段时刻换场，边界不重置状态；它不检查按到达判据切换、物理动力学或任务成功。

| 方法 | 局部位置 RMS | 不重置状态的连续位置 RMS | 结果 |
| --- | ---: | ---: | --- |
| 原整命令段、项目现有拟合器 | 89.183 mm | 同左 | 位置、姿态、到达超时均未通过 |
| 整命令段、SEDS 1.95 + Octave SQP 兼容试跑 | 91.953 mm | 同左 | 稳定性复核为负定，但名义验收未通过，优化到达上限 |
| 已有方案的四段 `[36,46] / [46,57] / [57,71] / [71,85]` | 4.988 mm | 8.516 mm | 四段分别通过；连续时间对齐 RMS 通过 |
| 无归档时自动二分的四段 `[36,48] / [48,60] / [60,72] / [72,85]` | 5.682 mm | 21.938 mm | 四段分别通过；连续时间对齐 RMS 未通过 |

连续四段方案的姿态 RMS 分别为已有方案 3.082°、自动二分 3.041°。本轮没有得到新的物理执行成功结果。8.516 mm 是时间对齐 RMS，并不表示末端达到 5 mm 或按到达判据切换成功。

## 原版源码试跑范围

文献：S. M. Khansari-Zadeh、A. Billard，*Learning Stable Nonlinear Dynamical Systems With Gaussian Mixture Models*，IEEE TRO，2011，DOI `10.1109/TRO.2011.2159412`。Crossref 原始响应另存于 `data/experiments/field_visualization_20261122/seds_crossref.json`。

取得的是保留作者版权及说明的 [SEDS 1.95 MATLAB 源码镜像](https://github.com/HongminWu/SEDS)，固定提交 `1afba5007caa942d208abcf589bacd3cb1c48b4c`，不是声称从作者现行官网下载的最新版本。该版本 README 标注 2013-02-12。作者源码未改动，原档及完整哈希留在实验目录。其许可限制再分发和修改，因此没有将作者库纳入项目源码。

本机没有 MATLAB。实验目录内解包 Octave 6.4.0 及依赖，不需要系统安装或 sudo。实际调用作者的 `initialize_SEDS`、`SEDS_Solver`、`SEDS_Solver_MSE` 和 `GMR`，输入为同一 3D 位置、测量速度、末端目标，位置及速度同时除以 0.1 m，保持物理时间单位；K=4、种子 20261122、最多 1000 次迭代。

试跑包含原惩罚式目标的 Octave `fminunc`、显式约束的 Octave SQP，以及主子式/特征值约束两类对照。`fmincon` 兼容层只负责转接 Octave SQP，不能称为 MATLAB 原生优化器完全复现。原惩罚输出及几次约束输出未通过独立负定性检查，均未当作有效场。

表中可复核的稳定输出采用特征值约束，兼容层为抵抗数值残差将 `lambda_max(A+A.T)<=0` 收紧 0.02/s；实际最大值为 -0.019489/s，负定性成立。其实际最小对称稳定裕度约 0.0097446/s，略小于项目标准 0.01/s；为无损表示该输出，诊断归档的解码配置记为 0.009/s。高斯门控和场速度与作者 `GMR` 输出逐点核对到 1e-8，并未改动现有训练拟合配置。该试跑 SQP 状态 103，达到 1000 次上限；它不是收敛最优解，也不是对原算法上限的判断。

这轮输出的点上速度 RMS 从现有拟合器约 0.05233 m/s 降到 0.02678 m/s，轨迹 RMS 仍未改善。仅优化点上速度误差或换求解器，不保证自由积分贴合整段轨迹。另一次 0.03/s 收紧试跑得到负定矩阵，但超出项目的矩阵范数/协方差条件数上限，保留为拒绝结果。

## 浏览器实现与实际验证

- 已处理 LIBERO 回合默认启用“自动分段与切换场”。先核验当前源数据与控制配置一致的完整原始示教方案，复核名义结果后复用；没有结果时后台拟合当前命令段，失败后递归二分，短段仍按原线性退化规则处理。保留未通过叶子段，不更改训练标签。
- 时间轴按公共边界归后一个场处理；会话缓存最近 32 个命令段。切换回合时取消旧回合后续拟合、丢弃过期结果。手动“诊断整命令段”或载入结果时关闭自动选择，可重新勾选。
- 界面分别报告局部验收和当前命令段的连续时间对齐误差。场、参考轨迹、名义轨迹、目标随片段切换；机器人仍按记录状态回放。
- 75 项相关测试通过；Ruff 和 `git diff --check` 通过。实际 GUI / LIBERO 子进程测试验证了 episode 6000 自动复用、40→50→40 帧换场与缓存、快速跨命令拖动；没有保存池的 episode 6001 自动完成后台拟合。无 Tk 回调错误。6001 当前命令段连续 RMS 为 20.656 mm，界面如实标记未通过。

自动三维叠加适用于处理后 LIBERO 清单内的所有回合，这是按需能力；没有逐一拟合验收 6500 条。原始 LIBERO HDF5 应先处理。ALOHA、PushT、xArm 或任意 LeRobot 状态尚未统一到同一世界坐标末端控制点，不会从无标定状态向量臆造三维场。在线策略仿真和实际场驱动执行尚未接入此显示面板。
