# 模型观察台

这个工具用于选择一个任务场景，观察模型现场推理与执行动作。每次只运行当前任务，默认暂停，完成或达到本次步数上限后保留现场，等待手动重置或切换。界面不计算任务集成功率，也不自动遍历整个数据集。

## 启动

在项目根目录执行：

```bash
env -u PYTHONPATH .venv/bin/python scripts/view_simulation.py
```

观察台使用一个窗口：顶部保留紧凑的模式切换，左侧选择任务，中央以 MuJoCo 三维视图为主。模型页将配置收在 360 像素的可滚动侧栏中，其余宽度交给三维视图。数据集浏览页默认将约 80% 的画面宽度分配给三维视图，任务标题下方的通栏放“演示回合”选择器，右侧辅助栏放录制相机和回放选项；拖动分隔条可以调整比例。分段条、时间轴和播放控件固定在底部，详细数值通过“显示数值”展开，下载入口收在左侧“更多数据选项”中。

## 场景选择

选择层级是“环境 / 数据集 → 任务集合 → 操作类型 → 具体任务 → 初始状态”。这里使用数据集配套的仿真任务与初始状态；演示数据文件不必下载，执行动作由所选模型现场生成。

| 环境 | 任务集合 | 操作类型与初始状态 |
| --- | --- | --- |
| LIBERO / Franka Panda | 空间关系、目标物体、目标要求、多步骤任务、综合任务 | 可筛选抓取放置、开合、堆叠、设备开关、推移和组合操作；初始状态编号来自任务的官方初始化文件 |
| ALOHA Sim / 双臂 | 方块交接、精细插接 | 初始状态编号作为随机种子偏移量，用于重现场景 |

操作类型按照任务文字描述归类，任务集合和任务编号保持上游 LIBERO 的顺序。实际初始状态数量会在场景打开后显示。

## 观看与模型控制

- 点击“打开所选场景”打开完整三维场景，默认暂停；默认同时在后台加载模型，可取消该勾选先观察场景。
- 模型就绪后点击“开始 / 继续”，或用“单步”执行一个控制步。
- “重置为当前初始状态”恢复同一场景并清空旧动作序列。“换一个初始状态”只更换当前任务的初态。
- “打开下一个任务”只打开当前筛选结果中的下一个任务，每次切换都需要手动点击。
- 完成后保留现场，不自动进入下一个回合。推理报错时也暂停并保留场景，便于检查和更换模型。
- 同一模型配置与检查点在切换任务时复用；切换不同模型后重新加载。默认权重首次使用时可能需要下载。
- 关闭当前场景会保留已加载模型，便于下次打开；关闭选择面板会关闭其创建的场景和模型服务。

内嵌三维视图支持左键旋转、右键平移、滚轮缩放；点击视图获得焦点后，空格暂停 / 继续、右方向键单步。“复位视角”恢复初始观察方向。三维自由视角与模型输入相机分别设置。默认隐藏 LIBERO 的绿色碰撞外壳。

## 模型适配

LIBERO 可选 π₀、π₀-FAST、π₀.₅ 的对应 LIBERO 配置；ALOHA 使用 `pi0_aloha_sim` 配置，输入和输出为双臂关节动作接口。模型配置和检查点必须与环境适配。

项目自带的 ALOHA Sim 默认权重针对方块交接。插接场景可以直接打开观察；需要进行插接推理时，填写兼容的插接检查点。工具不会自动把 LIBERO 单臂权重用于 ALOHA 双臂。

“加载 / 切换模型”使用当前环境兼容的配置及自定义检查点。自定义权重除了结构兼容，还需要对应的数据变换与归一化统计；工具会报告加载或推理错误。

## 图形与输出

界面统一选择系统可用的中文无衬线字体，当前机器使用思源黑体（Noto Sans CJK SC）；动作和状态数值使用 DejaVu Sans Mono。Linux 上优先使用相同 Python 版本的系统 Tk 字体渲染库，避免独立 Python 附带的 Tk 退回点阵字体。

仿真渲染仍在独立进程中运行，以兼容主环境和 LIBERO 的依赖；通过有容量上限的 RGB 共享缓冲区将最新画面显示在主窗口中，不生成回放视频。视图尺寸随布局调整，最高渲染尺寸为 1280×960。内嵌视图提供场景和轨迹观察，原生 MuJoCo 设置侧栏未嵌入。

默认勾选“使用软件绘制三维界面”，适用于当前机器的图形驱动状态。该设置仅作用于场景进程；模型服务仍使用 GPU。图形驱动正常的机器可以取消。

观看默认不导出视频或评测结果，只保留模型服务日志于 `data/sim_inspector/`。面板显示当前控制步、任务指令、模型状态与单次推理耗时，便于定位等待、失败或动作异常。

旧的批量评测入口 `scripts/run_franka_sim.py --mode full` 保留独立使用，观察台不会调用它。

## 后续建议

优先补充下面这些用于人工观察的功能：

1. 保存 / 恢复一次观看配置，记录环境、任务、初态、种子、模型和检查点，方便重现问题。
2. 手动录像和截图，保存用户选中的片段。
3. 在同一初始状态下手动切换两个模型，对照动作差异；不汇总整个任务集的性能。
4. 可选显示末端目标、动作轨迹与夹爪开合，帮助判断状态、动作或坐标系适配问题。

扩展环境时优先考虑 RoboCasa 的厨房交互场景、CALVIN 的语言指令操作；需要更丰富的机器人与接触任务时再考虑 ManiSkill。它们需要独立的观测 / 动作适配、依赖环境和匹配检查点，不能仅添加数据集名称后宣称模型已经适配。尚未接入的环境不显示在可用菜单中。

## 数据集浏览

顶部“模型仿真验证”和“数据集浏览”使用独立导航按钮，选中项的字号、宽度与高度都会增大，并显示绿色粗体。

“数据集浏览”默认进入数据集总览。卡片展示本地真实演示首帧、机器人、内容简介、完整元数据中的任务 / 回合数、本地可播放回合数和相机数。缩略图只解码一个本地回合的首帧，不批量播放或评测数据集。

进入数据集后，左侧直接列出元数据中的完整任务目录，支持中英文搜索、操作类型筛选和“只看本地可播放”。已识别的演示提供中文说明，并保留原始任务指令。每项任务显示“本地 / 总回合”数量；未标注的总数显示“—”。没有下载的任务仍可查看说明；已接入数据源且元数据提供对应回合时，可点击下载该任务的一个演示回合。仅有元数据的 LeRobot 目录也可以浏览任务目录，播放控件保持禁用。

观察台的“数据集浏览”页签用于观看已记录的演示，以及逐帧检查图像、动作和机器人状态。浏览不加载策略模型。可以在本地数据集下拉框中选择已下载样例，也可以打开自己的数据目录或 HDF5 文件。

操作顺序：选择数据集 → 操作类型 → 任务指令 → 演示回合 → 录制相机。“演示回合”位于三维视图上方，横跨三维与录制相机区域，便于查看完整名称。支持播放 / 暂停、前后逐帧、拖动进度和 0.25× / 0.5× / 1× / 2× 播放速度。动力系统场快照在后台预取，分段边界只切换已缓存的场，不在播放主线程中重新采样。三维回放进程与数据时间轴异步运行；软件渲染较慢时三维视图保留最新待显示帧并跳过中间渲染帧，录制画面和时间轴仍按源时间播放。较慢的存储或解码会限制实际播放速度。回合末尾保留最后一帧，不自动跳转到下一个回合。切换到其他页签时暂停数据播放。

底部“显示数值”可展开所选帧的动作、机器人状态，以及文件提供的时间戳、奖励和终止标记。原始 HDF5 的图像方向可能取决于采集设置，可以勾选“上下翻转录制画面”。图像保持宽高比；磁盘扫描与解码在后台进行，只缓存当前 Parquet 行组中所选相机及数值字段，不加载整个数据集。

| 数据格式 | 录制画面与数值 | 完整三维回放 |
| --- | --- | --- |
| LeRobot v2.0 / v2.1 | 支持 `meta/info.json`、回合 Parquet；视频相机及 Parquet 内嵌图像 / 图像路径 | 普通图像和机器人状态不足以恢复完整场景；可通过 `meta/replay.json` 显式关联来源演示 |
| LIBERO 原始 HDF5 | 支持 `data/demo_*/obs/*rgb`、`actions` 与机器人状态 | 回合包含 `model_file` XML 和 `states` 时启用 |
| ALOHA 原始 HDF5 | 支持 `observations/images/*` 的原始 RGB / 压缩图像、`observations/qpos` 和 `action` | 当前提供录制相机浏览 |

三维回放显示在浏览页内，支持自由旋转、平移、缩放和视角复位。处理后的 LIBERO 数据默认勾选“自动加载三维视图”，切换任务或回合会自动加载。也可点击右侧“加载三维回放”；手动取消自动加载后，本次会话会保留该选择。回放直接恢复每一帧记录的仿真状态，三维视图和录制相机共用播放与进度条；点击三维视图后，空格、右方向键也可以暂停或逐帧。需要匹配的 LIBERO 资源与独立仿真环境。它用于查看数据中的记录，不会调用策略或通过重新执行动作生成一条新轨迹。

LeRobot v3、RLDS / TFRecord 和任意格式的普通视频目录尚未直接接入。浏览器会提示不兼容布局；可以加载本项目的 LeRobot v2 数据或原始 HDF5。目录中的模型运行录像不会被标记为数据集演示。

左侧“更多数据选项”中的“添加一个演示回合”提供下列数据源，输入回合编号后只下载该回合的 Parquet、相机视频和必要元数据，不下载整套数据：

| --- | --- | --- |

也可直接启动到某个本地数据集：


## 数据处理时实时观看

可直接打开一个本地数据目录或 HDF5 文件，并在选择回合时加载内嵌三维视图、检测后续文件更新：

```bash
env -u PYTHONPATH .venv/bin/python scripts/view_simulation.py \
  --dataset data/datasets/raw/libero \
  --replay --watch
```

`--replay` 对应界面中的“自动加载三维视图”；`--watch` 对应“自动检测文件更新”。默认暂停，点击“播放”后开始观看。播放、暂停、单步和拖动进度使用同一时间轴；录制画面、当前帧数值与 MuJoCo 状态更新后才继续下一帧。存储、解码或绘制较慢时，实际播放速度会降低。

“重新载入当前数据”可以手动更新文件。自动检测约每秒检查一次：通过原子替换发布的新文件可以在下一次检查后载入；原地修改的文件需要连续两次检查结果一致后重新读取。它保留当前任务、回合、帧位置、相机和筛选条件；更新后回合变短时，把位置限制在新回合的最后一帧。原先正在播放时，在更新完成后继续。原始回放来源和场景未变时，内嵌三维视图与观看角度保留；场景模型发生变化时重建渲染场景并恢复视角。

建议处理程序写入临时文件，关闭文件后用 `os.replace(temporary, destination)` 发布结果。不要边写边覆盖当前正在观看的 HDF5 或 Parquet。读取暂时失败时保留上一帧；开启自动检测后会重试。这里观看的是已经发布到文件的数据快照，不接收尚未完成写入的逐步仿真流。

### 直接观看 LIBERO v2 命令分段

```bash
env -u PYTHONPATH .venv/bin/python scripts/view_simulation.py \
  --dataset data/processed/libero_v2 --replay
```

浏览器直接读取处理清单，按需打开所选回合及原始来源，不复制或重新导出演示。彩色条对应完整夹爪命令区间；点击色块、选择区间，或使用“上一段 / 下一段”跳转。“播放此段”播放到区间的段尾观测后暂停，录制图像与三维状态同步。

MuJoCo 内叠加按区间着色的末端轨迹，配色与彩色条一致。当前段加粗，白点显示当前位置，边界球标注段号；“三维轨迹 / 只看当前段 / 分段端点”即时控制叠加。初次加载时视角对准轨迹所在区域，可在内嵌视图中用鼠标旋转、平移和缩放。

彩色条显示源示教的夹爪命令区间候选；下方“动力系统场”默认自动准备当前片段的场，并随时间轴切换。命令区间可以进一步分成多个固定场。拟合与连续执行的条件见[参考动力系统入口](field_teachers.md)。初始录制图像缺失时显示提示；终端图像与本体仍保留，但没有对应的完整仿真状态，到达终端观测时清空三维视图并显示缺失提示，不重复前一状态。开启自动加载时，跳回有完整状态的观测会自动恢复三维回放；关闭自动加载时可手动点击“加载三维回放”。分段图导出与数据语义见 [LIBERO 数据处理](data_processing.md#在仿真中观看分段)。

### 手动观看过点场样例

在“动力系统拟合”区域点击“载入拟合结果…”，可载入已完成独立审计的高斯场单回合 JSON。先选择与样例相同的数据集和回合，例如处理后 LIBERO v2 的回合索引 6000，对应 `data/experiments/dynamics_passthrough_20261123/v5/libero/episode_06000.json`。载入后，“配置”会在当前会话显示“长片段/过点场”，彩色时间轴与场随片段同步切换；LIBERO 显示三维场，其他四类数据使用原生状态投影，支持“播放区间”，无需三维机器人快照。

载入器会核对来源、回合和缓存散列，并从参数重新积分。失败片段允许查看并显示原因；完整性通过不等于全部片段拟合通过。手动样例不会发布为全量默认配置，自动发现仍要求完整数据集构建和审计。位置场使用片段之后的目标减少提前收敛，真实停留和最终终点保留；状态连续不代表速度连续。细节与验收见[段末减速与过点场](dataset_dynamics.md#段末减速与过点场)。已运行窗口不自动更新源码，新增入口在下次启动时生效。

### 处理后仍保存完整仿真状态

如果算法处理了轨迹，并希望看到处理后的实际状态，保存为 LIBERO 兼容的 HDF5：

```text
processed.hdf5
└── data/
    └── demo_0/
        ├── attrs["model_file"] = 对应场景的完整 MuJoCo XML
        ├── attrs["fps"] = 播放帧率（可选，覆盖数据集帧率）
        ├── attrs["task"] = 任务指令（可选）
        ├── states       [T, 1+nq+nv+na]
        ├── actions      [T, action_dim]（可选）
        └── obs/*rgb     [T, H, W, 3]（可选）
```

`states` 每帧依次为仿真时间、`qpos`、`qvel` 和激活状态 `act`，须与 XML 的模型维数一致且数值有限。XML 引用的网格、纹理等资源须在本地可访问；原始 LIBERO 的旧资源目录会自动重定位。没有录制图像的回合也能通过三维视图观看；数值区会显示完整 `states` 和可用动作。此模式直接恢复处理后保存的状态。普通机器人关节向量、末端位姿或修改后的动作本身不足以确定场景内所有物体的位置。

### LeRobot 处理结果与来源演示对齐

对筛选、裁剪、重排或降采样后的 LeRobot v2 数据，可以额外保存 `meta/replay.json`，保留它与原始完整场景的逐帧对应关系：

```json
{
  "version": 1,
  "episodes": {
    "0": {
      "path": "../../datasets/raw/libero/libero_90/example_demo.hdf5",
      "group": "data/demo_0",
      "frame_indices": [0, 2, 4, 6]
    }
  }
}
```

`episodes` 的键是处理后数据的 `episode_index`。`path` 相对于**处理后数据集根目录**，也可使用绝对路径；`group` 是来源 HDF5 内的回合组。`frame_indices[i]` 明确指出处理后第 `i` 帧对应来源的第几帧，长度必须等于处理后回合的帧数，编号必须在来源范围内。重复帧和重排允许；两边帧数相同且逐帧一致时可省略映射。

该模式在界面标注为“原始参考回放”：三维视图显示来源记录的完整场景，数值区显示处理后的动作和机器人状态。修改动作、归一化状态或重标注奖励不会自动改变原始场景轨迹。需要观察修改后的运动时，应先用匹配环境执行或求解出新的完整仿真状态，再按上一节保存。无效映射会显示原因，并保留可用的录制画面浏览，不猜测对应关系。

```bash
  --group data/demo_0 \
  --stride 2 \
  --output data/processed_examples/libero_stride2

# 此示例已经在本机生成，可以直接执行以下观看命令。
env -u PYTHONPATH .venv/bin/python scripts/view_simulation.py \
  --dataset data/processed_examples/libero_stride2 \
  --replay --watch
```

还可用 `--start`、`--stop` 裁剪来源帧范围，或用 `--camera` 选择录制相机。导出帧率为来源帧率除以采样步长，保持原演示的时间尺度。该脚本提供单回合浏览示例；训练时的数据变换、训练划分和归一化统计仍需按算法配置准备。

本机另有 `data/processed_examples/libero_states_only.hdf5`，演示不带录制图像、只保存完整 XML、仿真状态和动作的观看方式。ALOHA、PushT、xArm 当前下载版本仍提供录制画面浏览；三维状态回放需要相应场景模型和完整状态，或与原始演示明确对齐的来源。

## 逐段动力系统场

“连续积分”表示分段处传递状态，没有位置重置；它不保证速度连续。每段的吸引目标若位于段末，紫色积分点仍可能先减速、换场后再加速。机器人本体是源状态回放，这两种运动分别读取与计算。可选的“长片段/过点场”把继续运动处的目标移到未来的源观测、在原边界切换，减少提前收敛；只有全量构建并通过完整性复核的配置才会出现在列表中。其停止保护、回退条件及速度诊断见[段末减速与过点场](dataset_dynamics.md#段末减速与过点场)。本轮样例不会自动替换当前默认场。

已登记全量离线结果的数据集，浏览器直接读取保存的动力系统分段、参数和连续积分轨迹；时间轴标题为“动力系统分段”。处理后 LIBERO 在三维场景显示真实场箭头与连续名义轨迹；ALOHA、PushT、xArm、LeRobot LIBERO 显示原坐标或关节空间投影，并同步录制画面。处理后 LIBERO 已完成的配置在面板中显示为“回放配置”“生产控制配置”“生产约束/放慢时间”；未通过场显示位置误差、姿态误差或到达时间原因。放慢配置保留原控制周期，时间标签同时显示源时间和放慢后的时间，播放按保存时长推进。分段条、误差报告和三维叠加随配置同步更新，暂停在同一帧也会重绘；每个配置独立缓存同编号场。完整数据缺少场景状态时不重建三维世界。源文件/清单变化、缓存散列或帧数不匹配时明确报错。构建、坐标和验收边界见[全量数据集动力系统](dataset_dynamics.md)。

已登记配置的紫色轨迹与误差报告来自保存的连续状态传递积分；验收同时包含局部起点和连续传递起点，分段边界没有状态重置。三维工作进程完成重绘后才确认叠加已更新，回报当前帧、场范围与段数。

以下按需诊断行为仅用于尚未登记完整离线结果的处理后 LIBERO。

已处理 LIBERO 数据浏览默认启用“自动分段与切换场”，适用于清单内的全部回合，不再要求逐段手动拟合。它先寻找 `data/experiments/` 中与当前源示教、清单和控制配置一致的完整方案，复核名义验收后复用；没有兼容方案时，在后台拟合当前命令区间，不通过则继续细分，最小子段保留约 5 个动作。无法通过的叶子段仍显示“未通过”，不会因细分而改写原验收门槛或训练标签。短于 8 个观测的拟合沿用线性退化形式，不提供完整 SEDS 参数监督。

拖动或播放时间轴时自动选择当前场，公共边界属于后一个场；同一会话缓存最近 32 个命令段，切回时直接复用。拟合期间可继续观看和调整视角；切换回合会取消后续旧段拟合并丢弃旧结果。“诊断整命令段”仍可检查整个命令区间是否适合一个固定场，可选择 SEDS 或线性吸引子；该操作及手动载入结果会关闭自动切换，重新勾选即可恢复。

每段报告从该段示教初态起算的位置/姿态 RMS 及到达验收；自动预览还单独显示本命令段按源时间连续切换、边界不重置状态的位置 RMS。各段分别通过不等于连续切换通过，后者也不等于按到达判据切换或物理执行成功。

三维视图以速度箭头显示位置场，橙线显示参考轨迹，紫线显示使用同一控制配置的名义积分，绿点显示目标；紫色游标随源时间移动。用“聚焦当前场”放大查看，用显示开关控制箭头和积分轨迹。场只在其来源片段的时间范围内显示，切回该范围会恢复。控制区显示同步位置误差、位置/姿态 RMS 和验收原因。“导出诊断图…”保存可独立查看的图像及来源 JSON/数值 NPZ。

这些是记录状态回放上的场诊断，机械臂仍显示示教状态；紫线没有驱动物理机械臂。箭头只表示三维位置速度，抓取与场的实际控制效果仍需完整执行核验。控制配置、参考轨迹来源和命令行导出见[场可视化说明](field_teachers.md#场可视化与逐段拟合诊断)。

自动三维场叠加目前覆盖已处理 LIBERO 的世界坐标末端轨迹。ALOHA、PushT、xArm 的录制画面浏览和任意 LeRobot 状态向量尚未统一为该坐标及控制点，原始 LIBERO HDF5 也须先经过处理入口；这些格式不自动生成三维位置场。

### 长片段与高斯场

“长片段/非线性场”配置在对应数据集全量构建并通过独立完整性审计后可用，观察台默认采用该配置。时间轴与三维箭头同步使用保存的新模型；没有核验世界场景映射的数据使用原状态空间投影，截面中其余维度固定当前源状态。配置仍可切回“回放配置”或已有的生产约束配置。

每段显示**原始观测转移数和源轨迹时长**，不足 10 个转移或 0.5 s 的运动段标为过短；完整短命令事件单独标注“仅诊断”。放慢后的时长不替代原始长度。新场的时间轴显示共同度量下的每步收缩界；拟合失败与稳定证书检查分别保留。切换场只采样保存的参数，不在浏览期间重新拟合。实现、构建与当前实测边界见[全量动力系统说明](dataset_dynamics.md#长片段分段与高斯稳定场2026-11-23)。
